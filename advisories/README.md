# Security advisories

Signed security advisories for terakota releases land in this directory as
numbered files, each carrying affected versions, severity, whether the flaw is
reachable in default configuration, the fixed version (or "no fix yet" with
mitigations), and a cosign signature over the advisory text — verifiable exactly
like a release download. Advisories are also published as GitHub Security
Advisories on this repository; watch the repository with security alerts enabled
to be notified. The full disclosure, support-window, and key-rotation process —
including the out-of-band path used if the signing key itself is ever compromised
— is in [SECURITY.md](../SECURITY.md).
